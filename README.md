# Process Hub — GitHub Pages Website

A static HTML/CSS/JavaScript website ready for GitHub Pages.

## Files
- `index.html` — main website
- `css/style.css` — design and responsive layout
- `js/app.js` — navigation, process data, search and rebate calculator

## Publish on GitHub Pages
1. Create a public GitHub repository.
2. Upload all files while keeping the folders.
3. Go to Settings → Pages.
4. Choose `Deploy from a branch`.
5. Choose `main` and `/ (root)`.
6. Save and wait for the deployment.

## Customize
Edit the `processes` array in `js/app.js` to add or change categories.
